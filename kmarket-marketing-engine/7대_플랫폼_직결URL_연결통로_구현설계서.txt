[1] 📸 인스타그램 (Instagram) & 🧵 스레드 (Threads) [Meta 계열]
--------------------------------------------------------------------------------
📌 플랫폼 방어막: 피드/릴스 본문 링크 클릭 불가. 본문 링크 시 도달률(Reach) 90% 강제 축소.
🛠️ GitHub 실전 오픈소스 및 해커들의 3대 직결 수법:

1. [댓글 ➔ 1초 DM 자동 봇 (Comment-to-DM)]
   - 핵심 라이브러리: `instagrapi` (스타 4.2k) / Meta Graph API Webhook
   - 해커들의 메커니즘:
     * 릴스/카드뉴스 5번에 "댓글에 [1] 남기면 이상형 진단 링크 즉시 전송" 배치.
     * 웹훅 또는 백그라운드 폴링 봇이 새 댓글 감지 (`@bot.on_comment`).
     * 댓글 작성자 ID를 낚아채어 0.1초 만에 개인 DM(다이렉트 메시지)으로 클릭 가능한
       파란색 공식 링크 발송:
       `client.direct_send("💖 3초 무료 이상형 진단: https://aura-ai-dating.vercel.app/", user_ids=[user_id])`
     * 유저는 푸시 알림 터치 ➔ DM 속 링크 클릭 ➔ 인앱 브라우저로 1초 만에 사이트 접속!
     * 효과: 댓글이 수백 개 폭발하면서 인스타 탐색 탭 알고리즘 노출 10배 폭발.

2. [스레드 1등 댓글 스텔스 링크 (First-Reply Stealth)]
   - 핵심 라이브러리: `threads-api` (Python)
   - 해커들의 메커니즘:
     * 본문에는 링크를 절대 넣지 않음 (알고리즘 페널티 회피 ➔ 노출 극대화).
     * 본문 게시 성공 응답(`thread_id`)이 떨어지자마자 0.5초 만에 봇이 내 글의
       첫 번째 답글(First Reply)로 링크 등록:
       `threads.reply(thread_id, "👉 3초 무료 입장: https://aura-ai-dating.vercel.app/")`
     * 스레드 댓글의 링크는 100% 파란색 하이퍼링크로 활성화되어 원클릭 직결!

3. [인스타 스토리 전체 화면 투명 링크 스티커]
   - 해커들의 메커니즘:
     * 스토리 업로드 시 'Link Sticker'를 생성하고, 화면 속 주황색 버튼 위에 딱 맞게 포개어 배치.
     * 화면을 탭하는 순간 즉시 공식 웹사이트가 오버레이 브라우저로 열림.


[2] 📱 틱톡 (TikTok)
--------------------------------------------------------------------------------
📌 플랫폼 방어막: 영상 설명란/댓글 링크 클릭 불가. PC 웹 봇 업로드 시 0회 감옥(Shadowban).
🛠️ GitHub 실전 오픈소스 및 해커들의 3대 직결 수법:

1. [Physical Phone Farm: 안드로이드 ADB + uiautomator2 자동화]
   - 핵심 GitHub 리포지토리:
     * `edde746/tiktok-uploader` (ADB 기반 모바일 제어)
     * `masterFuf/taktik-bot` (uiautomator2 기반 안드로이드 틱톡 자동화)
   - 해커들의 메커니즘:
     * PC 웹을 버리고, USB로 연결된 실제 안드로이드 폰(갤럭시)을 조종.
     * `adb push video.mp4 /sdcard/DCIM/Camera/` ➔ 영상 0.5초 고속 전송.
     * 안드로이드 공유 인텐트 호출로 틱톡 편집 창 0.1초 직결:
       `adb shell am start -a android.intent.action.SEND -t video/mp4 -p com.zhiliaoapp.musically`
     * 틱톡 서버에는 "진짜 삼성 갤럭시 + 통신사 IP + 진짜 틱톡 앱"으로 찍혀 **0회 감옥 100% 원천 박멸!**

2. [화면 속 주황색 버튼 위 '@계정 멘션 스티커' 오버레이]
   - 해커들의 메커니즘:
     * 틱톡 앱 편집 창에서 `@aura_dating` 멘션 스티커를 생성.
     * 엔딩 3초의 주황색 버튼("👉 무료 시작하기 >") 위치에 스티커를 포개어 배치.
     * 유저가 버튼을 터치하는 순간 프로필로 0.1초 만에 이동 ➔ 프로필 상단 파란 링크 클릭!

3. [틱톡 프로필 ➔ 인스타/유튜브 공식 아이콘 무료 연동]
   - 틱톡 프로필 편집에서 인스타/유튜브를 연동하면 공식 아이콘 버튼이 생성되어
     서류 인증 없이도 인스타/유튜브로 유저를 넘겨 직결 유입 완성.

📌 플랫폼 방어막: 2023년 말부터 쇼츠 본문 및 댓글의 모든 외부 링크 클릭 차단.
🛠️ GitHub 실전 오픈소스 및 해커들의 2대 직결 수법:

1. [관련 동영상(Related Video) 브릿지 루프 자동화]
   - 핵심 GitHub 리포지토리: `youtube-shorts-uploader` (Playwright 스튜디오 제어)
   - 해커들의 메커니즘:
     * 채널에 3초짜리 롱폼 영상("💖 아우라 AI 데이팅 1초 무료 가입") 1개 상시 고정 업로드.
     * 쇼츠 발행 시 유튜브 스튜디오에서 `relatedVideoId` 항목에 해당 롱폼 영상 ID를 지정.
     * 쇼츠 재생 시 좌측 하단에 `▶ 💖 아우라 AI 데이팅 1초 무료 가입` 공식 클릭 배너 자동 노출.
     * 터치 1번으로 롱폼으로 이동하며, 롱폼 본문/댓글의 파란색 링크는 100% 클릭 가능!

2. [쇼츠 좌하단 채널 핸들(@aura_official) 터치 유도]
   - 쇼츠 좌하단 채널 프로필 아이콘 ➔ 채널 홈 상단 구글 공인 웹사이트 파란 링크로 유도.


[4] 🟢 네이버 블로그 & 카페 & 🎬 네이버 클립
--------------------------------------------------------------------------------
📌 플랫폼 방어막: 외부 무료 도메인(Vercel 등) 반복 기입 시 상업성 저품질/블라인드.
🛠️ GitHub 실전 오픈소스 및 해커들의 3대 직결 수법:

1. [스마트에디터 ONE: 사진 전체 사슬 링크 (Image Hyperlink)]
   - 핵심 GitHub 리포지토리: `naver-blog-auto-post` (Playwright)
   - 해커들의 메커니즘:
     * 본문에 카드뉴스 5장 삽입 ➔ 4번 또는 5번 사진 DOM 선택:
       `page.locator("div.se-image-resource, img.se-image-resource").last.click()`
     * 상단 툴바의 [링크(사슬)] 버튼 클릭 ➔ URL 입력 ➔ Enter.
     * 유저가 사진 아무 데나 누르는 순간 사진 확대 대신 즉시 공식 웹사이트로 0.5초 만에 이동!

2. [네이버 modoo(모두) 도메인 클로킹 브릿지 (100% 면제)]
   - 해커들의 메커니즘:
     * 외부 링크 직접 삽입 대신, 네이버 공식 모바일 빌더인 `https://aura.modoo.at` 1장 제작.
     * 사진에 modoo.at 링크를 걸면, 네이버는 자기네 사이트 링크이므로 검열/저품질 0% 완전 통과!
     * modoo 페이지 속에서 공식 웹사이트로 0.5초 만에 자동 리다이렉트.

3. [네이버 클립 '블로그 글 스티커' 융합 연동]
   - 클립 영상 화면 위에 내 [네이버 블로그 글 스티커]를 공식 부착.
   - 유저가 클립을 보며 스티커 터치 ➔ 블로그로 이동 ➔ 블로그 사진 클릭으로 공식 웹사이트 직결!
