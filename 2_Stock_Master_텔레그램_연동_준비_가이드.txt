📈 Stock Master AI 텔레그램 실전 연동 준비 가이드 (메모장 저장용)
================================================================================

나중에 텔레그램 엔진을 본격 가동할 때 아래 2가지만 준비해서 알려주시면 1초 만에 연결됩니다!

--------------------------------------------------------------------------------
1. 📱 텔레그램 방 초대 링크 (웹앱 배너 클릭 시 방문자가 입장할 주소)
--------------------------------------------------------------------------------
- 방법:
  1) 텔레그램 앱 실행 ➔ [새 채널 만들기] 또는 [새 그룹 만들기]
  2) 채널 이름 설정 (예: Stock Master VIP 시황룸)
  3) 공개 링크 또는 초대 링크 생성 (예: https://t.me/내주식방이름 또는 https://t.me/+초대코드)
- 적용 위치:
  - 파일: C:\Users\zkfnt\Desktop\stock ai\stock\src\components\Dashboard\TelegramLeadBanner.jsx
  - 코드: const TELEGRAM_URL = "실제_초대_링크";

--------------------------------------------------------------------------------
2. 🤖 텔레그램 봇 토큰 & 방 ID (제미나이 글을 매일 08:30 자동 발송할 로봇)
--------------------------------------------------------------------------------
- 방법:
  1) 텔레그램 검색창에서 @BotFather 검색 후 시작(/start)
  2) /newbot 입력 ➔ 봇 이름 & 아이디 설정
  3) 발급된 [HTTP API Token] 복사 (예: 1234567890:ABCdefGHIjklMNO...)
  4) 내 텔레그램 채널/그룹의 [관리자(Administrator)]로 위에서 만든 봇을 추가
- 적용 위치:
  - 파일 1: C:\Users\zkfnt\Desktop\한국 마케팅봇\kmarket-marketing-engine\brands\stock\accounts.json
    "telegram_bot_token": "발급받은_토큰",
    "telegram_chat_id": "@내채널아이디 또는 -100숫자"
  - 파일 2: .env 파일에 환경변수 등록

--------------------------------------------------------------------------------
3. 🚀 연동 후 자동화 동작 흐름
--------------------------------------------------------------------------------
1) 구글/네이버 검색 유입 ➔ 주식 웹앱(stockmaster-ai) 방문
2) 포트폴리오 하단 배너 클릭 ➔ 내 텔레그램 방으로 1초 입장 (회원 자동 모집)
3) 제미나이 AI가 매일 오전 08:30 장전 모닝 브리핑 및 외인/기관 수급 특징주 자동 작성
4) 마케팅봇이 내 텔레그램 방으로 실시간 자동 발송!
