## 📸 3. 인스타그램 & 페이스북 [4장 카드뉴스] 연결 체계

인스타그램 피드(캐러셀)와 페이스북 페이지 앨범에 **매일 3회 정시 자동 발행**되는 고품질 카드뉴스 시스템입니다.

```
[ 4장 카드뉴스(캐러셀) 표준 구성 ]

┌───────────────┐ ┌───────────────┐ ┌───────────────┐ ┌───────────────┐
│ 1장: 후킹 표지 │ │ 2장: 핵심 내역│ │ 3장: 상세 정보│ │ 4장: CTA 전환 │
│               │ │               │ │               │ │               │
│ • 0원 나눔 밥솥│ │ • 제품 실물상태│ │ • 직거래 지역 │ │ • "프로필링크"│
│ • 환급 240만원│ │ • 조특법 요건 │ │ • 환급 가능액 │ │ • "구글 검색" │
└───────────────┘ └───────────────┘ └───────────────┘ └───────────────┘
```

* **🎨 K-Market 카드뉴스**: 실물 매물 이미지 + 0원 나눔 뱃지 + 지역(화성/안산 등) 현지화 렌더링.
* **💰 EasyTax 카드뉴스**: 국세환급금 통지서 + 1인당 평균 수령액 + 17개국 모국어 텍스트 오버레이.
* **🚀 배포 방식**: 봇이 4장 이미지를 자동 합성 후 인스타그램 Graph API 및 페이스북 페이지 API로 동시 게시.

## 💼 8. 세무사 봇(Tax-Bot) 파이프라인 연계

```
[ 숏폼 / 카드뉴스 / 스레드 / 페북 / 블로그 ] 5각 편대로 외국인 유입
                      ↓
[ 모국어 지원 외국인 전용 랜딩페이지 / 카톡 / 텔레그램 ]
                      ↓  ① 모국어 홈택스 가입 및 간편인증
                      ↓  ② 세무대리 수임 동의 원터치 처리
[ 세무사 전용 봇 (Tax-Bot) ]
                      ↓  ③ 국세청 원천징수영수증 자동 스크래핑
                      ↓  ④ 조특법 30조 외국인 감면 환급액 자동 산출
                      ↓  ⑤ 전자 세무 계약 체결 & 환급 신청 제출
[ 국세청 환급금 본인 계좌 입금 완료 ]
                      ↓
[ 수수료 정산 ] 환급액의 10~20% 자동 정산 (건당 10~20만 원 수익)
```
