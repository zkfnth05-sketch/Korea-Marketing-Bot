## 📌 1. 프로젝트 비전 및 핵심 목표

> **"정지된 사진 슬라이드를 넘어, 카메라를 정면으로 응시하며 17개국어로 직접 말하고 연기하는 '진짜 실사 AI 인플루언서' 30초 숏폼을 100% 무인 자동 생산한다."**

* **기존 방식의 한계**: 사진 5장 + 줌인/줌아웃 효과 + 오디오 나레이션 ➡️ 시청 지속 시간(Retention) 한계, 카드뉴스형 비디오로 인식됨.
* **혁신 방식의 가치**: 
  1. **완벽한 입술/치아/턱 립싱크 (Lip-Sync)**: 대본 발음에 1:1로 일치하는 입 모양 연기.
  2. **살아있는 인체 생체 반응 (Micro-Motion)**: 눈 깜빡임, 눈썹 움직임, 자연스러운 고개 끄덕임.
  3. **틱톡/릴스/쇼츠 알고리즘 우대**: '실제 사람이 말하는 얼굴 비디오'로 인식되어 노출(Impression)과 바이럴 전환율 5~10배 폭발.

## 🎯 3. AI 영상 업계 3대 핵심 난제 극복 아키텍처

대표님께서 제기하신 실무 오류들을 우리 봇 아키텍처에서 100% 원천 해결합니다.

```
┌─────────────────────────┬─────────────────────────┬─────────────────────────────────┐
│       발생 가능한 문제    │        근본적 원인       │       우리 봇의 정석 해결책      │
├─────────────────────────┼─────────────────────────┼─────────────────────────────────┤
│ 1. 서양/중국풍 찌꺼기   │ 오픈소스 AI의 서양/중국 │ 한국 산단/거리 배경 프롬프트    │
│    혼입 현상            │ 데이터 편향             │ + 17개국 에스닉 네거티브 필터   │
├─────────────────────────┼─────────────────────────┼─────────────────────────────────┤
│ 2. 얼굴/배경이 괴물처럼 │ 텍스트 ➡️ 바로 영상    │ 무조건 2단계 [I2V] 방식 고정    │
│    녹아내리고 일그러짐  │ (T2V) 생성의 한계       │ (완벽한 사진 픽스 ➡️ 표정 연기) │
├─────────────────────────┼─────────────────────────┼─────────────────────────────────┤
│ 3. 배경의 문화적 모호함 │ "Korean street" 등 모호 │ 제미나이 대본 단계에서          │
│    (홍콩/일본 거리 출력)│ 한 영어 프롬프트        │ '한글 간판', '산단 게이트' 주입 │
└─────────────────────────┴─────────────────────────┴─────────────────────────────────┘
```

### [원칙 1] T2V 절대 배제, 100% 무결점 I2V (Image-to-Video) 채택
* 텍스트에서 바로 동영상을 생성하는 T2V는 손가락 훼손과 얼굴 녹아내림이 빈번합니다.
* 따라서 **[1단계]** Gemini를 통해 결점 없는 극실사 얼굴 앵커 사진(Image)을 먼저 생성하여 검증한 후,
* **[2단계]** 그 사진을 로컬 GPU(LivePortrait/MuseTalk)로 넘겨 입 모양과 표정만 살려내는 **I2V 방식**으로 무결성을 유지합니다.

### [원칙 2] 한국 로컬 랜드마크 디테일 토큰 주입
* 제미나이 프롬프트 빌더에 아래와 같은 한국형 실존 디테일을 강제 주입합니다:
  * `"Korean Hangul signage like '편의점', '식당', typical Korean industrial complex asphalt road, green street signs, clean modern Korean background"`
* 이를 통해 외국인 노동자가 한국에서 진짜 생활하며 촬영한 듯한 100% 현장감을 구현합니다.

### [원칙 3] 17개국 에스닉 앵커와 한국 배경의 분리
* 인물은 각 나라별 타깃 페르소나(베트남, 우즈벡, 태국, 네팔 등 고유 이목구비)를 고정하고,
* 배경만 한국의 일터와 생활권으로 분리 결합하여 이질감 없는 완벽한 몰입감을 부여합니다.

## ⏱️ 4. 30초 말하는 숏폼 표준 타임라인 설계 (전환율 1위 공식)

30초 내내 사람 얼굴만 나오면 시청자가 지루함을 느끼므로, **틱톡/릴스 1위 공식인 [하이브리드 시네마틱 30초 구조]**로 연출합니다.

```
0초                  6초                                22초                 30초
├─────────────────────┼──────────────────────────────────┼─────────────────────┤
│  [1] 인물 훅(Hook)  │     [2] 실물 앱 시연 & 증빙      │   [3] 인물 클로징   │
│ • AI 인물 정면 응시 │ • 스마트폰 간편조회 스크린캐스트 │ • AI 인물 손짓 연기 │
│ • 입모양 립싱크     │ • 모바일 뱅킹 입금 배너 팝업     │ • "프로필 링크 클릭"│
│ • 충격적 질문 발화  │ • 세무 특례 자막 & 나레이션      │ • 최종 CTA 액션     │
└─────────────────────┴──────────────────────────────────┴─────────────────────┘
```

* **Scene 1 (00:00 ~ 00:06) - 시선 강탈 훅 (Live Avatar)**
  * AI 인물이 카메라를 뚫어져라 응시하며 첫 멘트를 던집니다.
  * *"외국인 세금 환급, 380만 원 그냥 버리고 계신가요? 3분 만에 확인하세요."*
* **Scene 2 (00:06 ~ 00:22) - 신뢰 증빙 & 해결책 (Screencast & Overlay)**
  * 인물 목소리가 이어지며, 화면 중앙에는 실제 EasyTax/K-Market 모바일 앱 간편조회 화면이 녹화된 비디오가 재생됩니다.
  * 화면 상단에는 `[신한/국민은행 +₩3,840,000 입금]` 푸시 배너가 팝업됩니다.
* **Scene 3 (00:22 ~ 00:30) - 행동 촉구 CTA (Closing Avatar)**
  * 다시 AI 인물이 화면에 등장하여 밝은 표정으로 손가락으로 아래를 가리킵니다.
  * *"지금 바로 프로필 링크를 누르고, 내 환급금을 무료로 조회해보세요!"*

## 🛠️ 5. 시스템 아키텍처 및 소프트웨어 모듈 설계 (모듈 분리 원칙)

기존의 안정적인 마케팅 엔진 코드를 훼손하지 않고, 독립된 전문 모듈을 새롭게 추가하여 연동합니다.

```
kmarket-marketing-engine/
│
├── core/
│   ├── tts_engine.py                   # (기존) 17개국 원어민 신경망 음성 합성
│   ├── motion_video_composer.py        # (기존) 1080x1920 9:16 자막/BGM/합성 엔진
│   ├── screencast_video_provider.py    # (기존) 실제 스마트폰 화면 녹화 클립 제공
│   └── connectors/
│       └── local_gpu_lipsync_driver.py # 🌟 [신규] 로컬 GPU I2V 립싱크 통신 드라이버
│
├── modules/
│   ├── shorts_easytax.py               # (기존) EasyTax 숏폼 오케스트레이터
│   ├── shorts_kmarket.py               # (기존) K-Market 숏폼 오케스트레이터
│   └── talking_avatar_factory.py       # 🌟 [신규] 30초 말하는 AI 아바타 통합 공장
```

### 신규 모듈 역할 정의
1. **`core/connectors/local_gpu_lipsync_driver.py`**
   * 고사양 NVIDIA GPU의 PyTorch 환경에서 LivePortrait / MuseTalk 모델을 로드하여,
   * `[인물 이미지 경로]` + `[TTS 음성 파일 경로]`를 받아 초당 30fps의 `[말하는 인물 영상.mp4]`를 생성하는 전용 드라이버.
2. **`modules/talking_avatar_factory.py`**
   * 30초 대본 작성 ➡️ 성우 음성 생성 ➡️ 립싱크 비디오 생성 ➡️ 자막/BGM/스크린캐스트 결합을 지휘하는 상위 팩토리.
