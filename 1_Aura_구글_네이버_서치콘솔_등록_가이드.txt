💖 [Aura 데이팅] 구글 서치콘솔 & 네이버 서치어드바이저 7,000개 색인 등록 가이드
========================================================================

대표님, Aura(AI 데이팅) 공식 웹사이트의 7,000개 초대형 색인 팡(국내 5,005개 + 글로벌 2,000개)을 
구글과 네이버 검색창에 완벽하게 노출시키기 위한 1분 등록 가이드입니다.

------------------------------------------------------------------------
📌 [1단계] Google Search Console 사이트맵 등록 (구글 검색 1위 노출)
------------------------------------------------------------------------
1. 브라우저에서 구글 서치콘솔에 접속하여 로그인합니다.
   👉 https://search.google.com/search-console

2. 좌측 상단 [속성 추가]를 누르고 Aura 공식 도메인을 입력합니다.
   👉 https://aura-ai-dating.vercel.app  (또는 대표님의 커스텀 도메인)

3. 소유권 확인 완료 후, 좌측 메뉴에서 [Sitemaps (사이트맵)]을 클릭합니다.

4. [새 사이트맵 추가] 입력칸에 아래와 같이 입력하고 [제출] 버튼을 누릅니다.
   👉 sitemaps/sitemap_aura.xml   (또는 sitemap.xml)

5. 완료! (구글 로봇이 전국 200개 핫플 + 16×16 MBTI + 영미/일본어 7,000개 페이지를 자동 색인합니다.)


------------------------------------------------------------------------
⚡ [2단계] Google Indexing API 실시간 초고속 색인 연동 (1~2시간 만에 노출)
------------------------------------------------------------------------
새 글이나 트렌드가 뜰 때마다 1~2시간 만에 구글 1페이지에 올리는 기능입니다.

1. Google Cloud Console 접속
   👉 https://console.cloud.google.com/

2. "Web Search Indexing API"를 검색하고 [사용] 버튼을 누릅니다.

3. [사용자 인증 정보] ➔ [서비스 계정 만들기] ➔ JSON 키를 다운로드합니다.

4. 구글 서치콘솔 [설정] ➔ [사용자 및 권한]에서 해당 서비스 계정 이메일을 [소유자(Owner)]로 추가합니다.

5. 다운로드한 키 파일 이름을 `service_account.json`으로 변경하여
   `kmarket-marketing-engine` 폴더 안에 넣어두시면 마케팅 봇이 24시간 자동으로 실시간 핑을 쏩니다!


------------------------------------------------------------------------
🟢 [3단계] 네이버 서치어드바이저 (Naver Search Advisor) 등록
------------------------------------------------------------------------
1. 네이버 서치어드바이저에 접속하여 네이버 아이디로 로그인합니다.
   👉 https://searchadvisor.naver.com/

2. [웹마스터 도구] ➔ 사이트 등록에 `https://aura-ai-dating.vercel.app` 입력

3. [요청] ➔ [사이트맵 제출] 메뉴로 이동하여 아래와 같이 입력하고 확인을 누릅니다.
   👉 sitemaps/sitemap_aura.xml

4. [요청] ➔ [웹 페이지 수집]에서 주요 핵심 URL(라운지, 핫플 등)을 입력하여 즉시 수집을 요청합니다.


------------------------------------------------------------------------
📁 로컬에 완성된 7,000개 사이트맵 및 SEO 정적 페이지 위치
------------------------------------------------------------------------

  • 🇯🇵 일본 2030 여성: 서울 카페 & 한일 커플 테마 = 1,000개
  • 🇺🇸 글로벌 여성: 서울 나홀로 여행 & 안전한 한국인 친구 테마 = 1,000개
